# Documentation language and claims

Human-facing research reports and campaign summaries should default to Japanese.
Machine-facing contracts, schemas, code, identifiers, and frozen preregistration fields may remain English.

Never alter numeric values, hashes, run IDs, paths, or statistical results during translation.
Retractions and limitations must remain visible.

Use calibrated scientific language. Distinguish:
- observed result
- interpretation
- plausible mechanism
- unsupported speculation
- external literature claim

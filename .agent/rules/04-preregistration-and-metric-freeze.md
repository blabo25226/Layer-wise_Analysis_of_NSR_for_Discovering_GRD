# Preregistration and metric freeze

Before final evaluation, freeze:
- primary hypothesis
- primary endpoint and statistical unit
- datasets/splits
- checkpoints/models
- baselines and ablations
- seeds
- search/training/decode budgets
- operator/equation constraints
- exclusions and failure policy
- supported / unsupported / undecidable criteria
- Go/No-Go gates
- compute ceiling
- required artifacts

After freeze, changes require a recorded deviation. If the change could be influenced by final results, create a new
cycle or mark the current result exploratory.

# Layer Analysis Contract

"Layer importance" is not one quantity.

Always identify which question is measured:
- probe/readout: information availability
- CKA/similarity: representation geometry
- gradient: optimization signal
- ablation/intervention: causal necessity/sensitivity
- IOLE/single-layer FT: adaptation capacity
- selective FT: multi-layer adaptation performance

Do not average these into one ranking without a preregistered scientific justification.

# Independent review output schema

Required sections:
- Scope reviewed
- Primary artifacts inspected
- Reproduction/checks performed
- CRITICAL findings
- MAJOR findings
- MINOR findings
- Alternative explanations
- Claim-by-claim assessment
- Replication recommendation
- Final verdict:
  ACCEPT_AS_NEGATIVE / ACCEPT_AS_PRELIMINARY / REPLICATE / REVISE_ANALYSIS / INVALIDATE

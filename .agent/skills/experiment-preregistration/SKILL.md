# Experiment Preregistration

Freeze the fields required by `.agent/rules/04-preregistration-and-metric-freeze.md`.

Have a second role attack the plan before freeze:
- leakage
- endpoint ambiguity
- unit-of-analysis mismatch
- unfair baseline budget
- missing positive/negative controls
- impossible gate
- hidden fallback
- insufficient artifact logging

Once frozen, record the exact plan path/version in `research_state.md`.

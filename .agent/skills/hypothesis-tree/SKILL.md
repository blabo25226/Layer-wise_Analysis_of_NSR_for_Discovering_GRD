# Hypothesis Tree

For every candidate record:
- falsifiable statement
- existing evidence
- competing explanations
- concrete falsifier
- expected information gain
- compute/engineering cost
- success interpretation
- failure interpretation
- what a negative result teaches
- novelty status
- dependencies and unverified assumptions

Prefer experiments that separate competing explanations.
Select by expected scientific information gain / cost, not expected benchmark improvement.

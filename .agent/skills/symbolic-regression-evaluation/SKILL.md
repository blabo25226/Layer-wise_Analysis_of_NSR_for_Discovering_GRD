# Symbolic Regression Evaluation

Analyze from raw/per-problem artifacts when possible.

Separate:
- fit metrics
- exact/skeleton/algebraic recovery
- variable recovery
- complexity
- valid/failure rate
- singularities/domain failures
- generalization
- compute/search budget
- layer representation/intervention/adaptation where relevant

Never call non-significance equivalence.
Make exclusions and invalid formula handling explicit.

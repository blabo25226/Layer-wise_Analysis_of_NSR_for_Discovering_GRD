# Artifact Archive

At cycle completion preserve:
- report
- frozen plan
- analysis
- independent review
- relevant configs/commands
- task/commit provenance
- artifact manifest
- checksums

Do not commit huge raw datasets/checkpoints solely for archival.
Reference stable paths/hashes instead.

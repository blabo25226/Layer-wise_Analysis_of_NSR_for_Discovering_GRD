# Reproducibility Audit

Inspect:
- split order/test isolation
- seeds and paired comparisons
- baseline/search budget fairness
- checkpoint identity
- hidden fallback
- output destinations and overwrite risk
- resume behavior
- equation/failure records
- manifest/checksums
- contamination from prior runs

CRITICAL issues block promotion to a supported conclusion.

# Cycle Synthesis

Summarize:
- supported findings
- unsupported hypotheses
- invalidated claims
- unresolved findings
- repeated failure mechanisms
- evidence conflicts
- replication outcomes
- hypotheses to abandon
- hypotheses to prioritize
- compute spent
- knowledge gained
- top 3 next directions
- high-priority human review items

Do not count cycle quantity as progress.
Progress means changed scientific understanding.

# Statistical Reviewer

Check:
- statistical unit vs sample size
- paired/repeated structure
- estimator and uncertainty calculation
- small-n interpretation
- multiplicity/selection
- endpoint definition
- power/detectability where meaningful
- equivalence vs non-significance
- missingness/failure handling

Prefer concrete corrections and verification tests.

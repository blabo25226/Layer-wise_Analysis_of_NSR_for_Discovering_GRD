# GPU_RUN3 研究成果まとめ

作成日: 2026-08-18
run-id: `gpu_run3_full_20260817`（本編）/ `gpu_run3_extended_1800s_groupB_20260818`（予算延長）
実行環境: RTX 2070 (8GB) / PyTorch 2.5.1+cu124 / Python 3.10.20
対象モデル: NDformer（公式checkpoint、17,715,713 パラメータ、encoder 2ブロック + decoder 2ブロック）

---

## 0. 要旨

GPU_RUN3は plan.md が定める二大目標——**ND²の公式再現**と**NDformerの層解析**——を実施した。

**ND²再現について。** 公式checkpointとMCTSにより、10 synthetic systems 中 **2系（Kuramoto、Michaelis–Menten）で真の数式を厳密に回復**した（3シード中それぞれ3/3、2/3）。NDformer誘導は unguided MCTS に対し明確に優位で、平均R²は 0.860 対 0.576、Kuramotoでは8桁の誤差差がついた。残り8系は回復に至らず、その失敗原因は**探索律速と識別可能性の2種類に分かれる**ことを、予算6倍の対照実験で分離した。

**層解析について。** decoder最終ブロック1層のみのfine-tuning（全パラメータの23.7%）が、全層fine-tuningの改善幅の**89%をhold-out testで達成**した。probe・IOLE・ablation・gradientの4指標が一致して同じ層を最上位に置く一方、**probeとactivation interventionの順位相関は−1.0**（完全逆転）であり、「読み出せること」と「因果的に効くこと」が乖離する事例を得た。

**両者の接続について。** 数式構造はencoderの2ブロック間で急激に形成される（貪欲rolloutのTEDが 31.1 → 8.9）。一方で層への介入がMCTSの最終的な数式発見を変えるかについては、**本runの予算では結論が出なかった**（後述 §6.3）。

## 3. 主目的A: ND²の再現

### 3.1 RQ2 — NDformer policyの再現（Phase 1）

公式checkpointを analysis-validation の 65問題・601例で teacher-forcing 評価した。

| 指標 | 値 |
|---|---|
| cross entropy | 2.097 |
| top-1 accuracy | 0.390 |
| top-5 accuracy | 0.783 |
| 真シンボルの平均順位 | 5.64 |
| policy entropy | 1.925 |
| valid rate | 1.000（失敗0件） |

policy entropy 1.925 は一様分布の log(50)=3.91 を大きく下回り、checkpointが実際に学習済みであることを確認した。シンボル別のCEは 0.19〜6.66 と広く分散しており、入力に依存しない退化した指標ではない。

### 3.2 RQ1 — synthetic benchmark（Phase 3、10系 × 3シード、各300秒）

| システム | exact | 平均TED | 平均RMSE | 平均R² |
|---|---|---|---|---|
| Kuramoto | **3/3** | 0.0 | 3.29e-07 | 1.0000 |
| Michaelis–Menten | **2/3** | 3.0 | 4.79e-04 | 1.0000 |
| Wilson–Cowan | 0/3 | 14.7 | 0.0104 | 0.9997 |
| gene regulatory | 0/3 | 15.3 | 0.1108 | 0.9992 |
| Lotka–Volterra | 0/3 | 22.3 | 0.0708 | 0.9210 |
| FitzHugh–Nagumo | 0/3 | 16.7 | 0.2987 | 0.8383 |
| SIS | 0/3 | 13.3 | 0.2522 | 0.8049 |
| homog. coupled Rössler | 0/3 | 14.7 | 1.512 | 0.7509 |
| coupled Rössler | 0/3 | 14.3 | 1.492 | 0.7431 |
| mutualistic population | 0/3 | 18.0 | 4.836 | 0.5448 |

回復に成功した2系の予測式:

```
Kuramoto  真: omega0 + 1.0*aggr(sin(sour(x) - targ(x)))
          予: (-0.0 + omega0) + (1.0*aggr(sin(sour(x) - targ(x))))

Michaelis–Menten  真: aggr(sour(regular(x, 2))) - x
                  予: (-1.0*x) + (1.0*aggr(sour(regular(x, 2))))
```

いずれも定数最適化に由来する冗長項を含むが数学的に同一であり、正規化によって exact と判定される。

### 3.3 NDformer誘導の効果

| 条件 | 平均R² | 平均TED | 平均探索ノード |
|---|---|---|---|
| NDformer誘導 | **0.860** | — | 少ない |
| unguided（一様） | 0.576 | 18.3 | 4,103 |

Kuramoto単体（Phase 2）での対比が最も明瞭である。

| | 誘導あり | 誘導なし |
|---|---|---|
| RMSE | **4.80e-08** | 1.208 |
| 探索ノード | 2,311 | 3,564 |
| 予測式 | 真値と一致 | `-0.7865*(-(-0.2508+omega0))` |

**誘導なしの方が多くのノードを展開したにもかかわらず、正解に到達していない。** 探索量ではなく探索の方向づけが効いていることを示す。

### 3.4 失敗要因の分離（予算延長実験）

シミュレータは真式を直接評価して目的変数を生成するため**データは無ノイズ**である。したがって「誤った式がR²≈1に到達している」場合、reward関数が真式と誤式を区別できていないことを意味し、これは計算時間では解決しない。この観点で失敗8系を分類した。

- **識別可能性律速**（FHN, WC, GR）: R² 0.838〜0.9997 で既に高い当てはまり。FitzHugh–Nagumoは1シードで**RMSE 3.3e-08・R²=1.0000000** に到達しながらTED 14。
- **探索律速の候補**（CR, HCR, MP）: R² 0.54〜0.75 で当てはまり自体が不足。

後者3系を予算6倍（1800秒、早期終了も無効化）で再実行し、システム・シード・シミュレーション条件を揃えた対照実験を行った。

| システム | seed | RMSE 300s→1800s | R² 300s→1800s | TED | exact |
|---|---|---|---|---|---|
| **HCR** | 101 | 1.518 → **3.35e-08** | 0.780 → **1.0000** | 13 → **0** | **✅** |
| HCR | 202 | 1.488 → 0.488 | 0.746 → 0.973 | 18 → 8 | |
| HCR | 303 | 1.529 → 0.490 | 0.727 → 0.972 | 13 → 8 | |
| MP | 101 | 3.562 → 3.416 | 0.568 → 0.602 | 17 → 15 | |
| MP | 202 | 4.226 → 3.841 | 0.582 → 0.655 | 19 → 16 | |
| MP | 303 | 6.722 → 5.616 | 0.485 → 0.640 | 18 → 15 | |
| CR | 101 | 1.497 → 1.445 | 0.864 → 0.873 | 13 → 14 | |
| CR | 202 | 1.498 → 1.480 | 0.711 → 0.718 | 16 → 16 | |
| CR | 303 | 1.481 → **1.481** | 0.6542 → **0.6542** | 14 → 14 | |

**結論は系ごとに異なる。**

- **HCR は探索律速だった。** 3シードすべてで大幅改善、seed 101 は真値を厳密に回復した。300秒版はネットワーク結合項 `aggr(sin(sour(x)-targ(x)))` を一度も発見できていなかった。
- **MP は未収束。** R²が全シードで単調改善（最大 0.485→0.640）しており、さらなる延長に余地がある。
- **CR は頭打ち。** seed 303 は6倍の予算で小数点以下4桁まで同一。探索時間は原因ではない。

「回復できなかった＝計算時間不足」と一括りにはできない、というのが本実験の結論である。

## 4. 主目的B: NDformerの層解析

解析対象は Transformer ブロック4層（encoder 2 + decoder 2）。GNN・embedding・出力headは対照として扱い、top-k選択には混ぜていない。

### 4.1 RQ3 — 層ごとの情報表現（Phase 4）

probeは `analysis_train` で学習し、式単位で分離された `analysis_validation` で評価。各スコアにラベルシャッフル対照を併置し、差分を報告する。

| probeタスク（スコア − 対照） | enc.0 | enc.1 | dec.0 | dec.1 |
|---|---|---|---|---|
| next_symbol | 0.013 | 0.038 | 0.308 | **0.343** |
| formula_root_operator | 0.114 | 0.136 | **0.296** | 0.166 |
| tree_size | −1.00 | −1.68 | −0.68 | −0.69 |
| gradient norm | 0.405 | 1.357 | 1.035 | **7.715** |

- **next_symbol は decoder 専用の情報である。** encoderの活性はデコード中のprefixに依存しないため、この結果は理論的に予測されるとおりであり、probe実装が健全であることの傍証になる。
- **tree_size は全層で対照を下回る明確なnull結果。** 数式の大きさは線形に読み出せない。
- gradient norm は深さとともに単調増加し、decoder最終層が突出する。

### 4.2 RQ6 — 数式構造はどの層で形成されるか（Phase 5）

各encoderブロックのmemoryを学習済みdecoderへ渡し、ND²自身の文法に従って貪欲rolloutで完全な式を生成、真値と比較した。

| encoderブロック | 真シンボル順位 | rollout TED | exact率 |
|---|---|---|---|
| layers.0 | 34.92 | **31.06** | 0.000 |
| layers.1 | 5.52 | **8.89** | 0.028 |

**数式構造はこの1ブロックの間で急激に形成される。** layer 0 の出力は退化した式（除算の深いネスト等）にとどまるのに対し、layer 1 からは36問題中1問題が貪欲デコードだけで厳密に回復される。

なお `encoder.layers.1` と `decoder.layers.1` の readout 指標が一致するのは数学的必然である。ND²の実際のpolicy headは `F.linear(out[:,1,:], token_embedding.weight)` であり、最終encoderブロックの出力はdecoderが通常受け取るmemoryそのものだからである。これらはbaselineの再現であって独立した測定ではない。

### 4.3 RQ4 — 層の因果的寄与（Phase 6）

validation 16問題の固定パネル上で、同一baseline（CE 2.273、top-1 0.383）との差分として測定。

| 層 | IOLE後CE | ΔCE (skip ablation) | ΔCE (mean介入) | 更新感度 |
|---|---|---|---|---|
| encoder.0 | 2.2631 | 0.560 | 1.350 | 0.00964 |
| encoder.1 | 2.2263 | 5.885 | 1.265 | 0.01177 |
| decoder.0 | 2.1941 | 0.654 | 1.137 | 0.00933 |
| decoder.1 | **2.1606** | **23.286** | 0.946 | 0.01155 |
| frozen / full | 2.2734 / 2.1766 | — | — | — |

**decoder最終層を1層だけ学習した条件（2.1606）が、全層fine-tuning（2.1766）を上回った。** 各stackの最終ブロックが、除去に対して最も脆く（ΔCE 5.9 / 23.3）、更新も最も大きい。

### 4.4 RQ5 — 少数層fine-tuning（Phase 7 validation / Phase 8 test）

| 条件 | 学習比 | validation CE | **test CE** | test top-1 |
|---|---|---|---|---|
| frozen | 0% | 2.1593 | 2.2599 | 0.360 |
| **top_1** (decoder.1) | 23.7% | 2.0331 | **2.0940** | 0.404 |
| top_3 | 65.3% | 2.0384 | 2.1383 | 0.409 |
| random_3 | 65.3% | 2.0392 | 2.1343 | 0.404 |
| full | 100% | 2.0201 | 2.0744 | 0.444 |

**top_1 は全層FTの改善幅の 89%（ΔCE 0.166 / 0.186）を、パラメータの23.7%で達成した。** さらに test split では **top_1 が top_3 を上回っている**。同一ステップ予算の下では、更新を3ブロックに分散させるより最上位1ブロックに集中させる方が良い。

**k=3のランダム対照は本アーキテクチャでは成立しない。** ランキング対象が4ブロックしかないため3要素の部分集合は4通りしかなく、実際 `random_3` は `top_3` と同一集合を引いた。k=1ならPhase 6のIOLEスイープ（全ブロックを同一予算で単独学習）がランダム1層選択の分布そのものなので、これを対照として使える：ランダム1層の期待値 2.2110 に対し top_1 は 2.1606 で、**0.050 の優位**がある。

### 4.5 指標間の一致（Phase 7）

| 比較 | Spearman |
|---|---|
| probe vs IOLE | **+1.0** |
| probe vs gradient | +0.8 |
| probe vs ablation | +0.8 |
| probe vs DecoderLens | 0.0 |
| probe vs activation intervention | **−1.0** |

**probeの順位はどの層をfine-tuneすべきかを完全に予測する一方、activation interventionの効果を完全に逆predictする。** plan.md §14 は不一致もそのまま報告することを求めており、これは §6.6 が混同を戒める「読み出せること」と「因果的に効くこと」の乖離の実例である。

平均順位によるconsensusは `decoder.1 > encoder.1 > decoder.0 > encoder.0`。

### 4.6 RQ8 — 事前学習分布との距離（Phase 9）

公式文法からサンプリングした800式のカタログに対し、44クエリの `retrieved_nearest_ted_skeleton` は平均 3.98。近似検索であり厳密な最近傍ではない。

## 5. 両目的の接続

数式構造はencoderの浅→深で急激に形成され（TED 31.1 → 8.9）、policyの生成能力はdecoder最終ブロックに集中する（IOLE最良、ablation最脆、gradient最大）。これらは互いに整合する。

一方で**「層解析で重要と判定された層への介入がND²全体の数式発見を変えるか」（RQ7）には、本runでは答えが出ていない。** Phase 8のtest MCTSは全条件で exact 0、平均TEDは 10.0〜12.5 で条件間の差が小さく、n=4問題では条件を分離できない。policyレベルの改善（CE 2.26 → 2.09）が formula-level の発見へ波及するかは未解決である。

## 6. 限界と留意点

### 6.1 アーキテクチャに起因する限界

NDformerはTransformerブロックが4層しかない（GPU_RUN2のNeSymReSは11層以上）。このため k=3 のランダム対照が成立せず、層ランキングの解像度も粗い。層数の多いモデルでの追試が望ましい。

### 6.2 計算予算に起因する限界

- synthetic benchmark は1問題あたり300秒。HCRの結果が示すとおり、この予算は少なくとも一部の系で律速していた。
- fine-tuningは120ステップ・バッチ4と小規模で、条件間の差は小さい。
- Phase 7/8のMCTS評価は4問題のみで、条件を分離する検出力が不足している。

### 6.3 方法論上の留意点

- **KURの公式ネットワークファイルが未取得。** Zenodoアーカイブにのみ同梱されるため、ER グラフ（50ノード/200エッジ）で代替し `used_er_fallback` を立てている。Kuramotoの成功はこの代替条件下でのものである。
- **正規化の定義がPhase 3の結果を見た後に確定した。** 事前登録された構造メトリクスを求める場合は `*_as_recorded` 列を変更前の値として扱われたい。ただしこの訂正は plan.md §11 の仕様要求（定数・可換性・符号の扱いを固定せよ）を満たすためのものであり、結果に合わせた閾値調整ではない。
- test splitはPhase 8で一度だけ評価し、その後に条件追加や再採点は行っていない。

### 6.4 本runで検出・修正した実装上の欠陥

解析結果の妥当性に直接影響した主なものを挙げる。詳細は provenance note を参照。

| 欠陥 | 影響 |
|---|---|
| 解析corpusがND²語彙外のトークンを使用 | Phase 1が全NaN、Phase 4がクラッシュ |
| `data_emb` が `no_grad` 下でキャッシュ | **encoderのgradientが恒等的に0** |
| probeが in-sample 評価、ridge過小 | hold-out R²が−1e13 |
| `random_state=0` をMCTSへ渡す | upstreamが偽と解釈し未シードの乱数に置換 |
| 定数・符号の正規化欠落（3件） | 正しい回復をexact 0と誤判定（KUR/MM/HCR） |
| TED timeout 未実装（plan §16.1） | 退化した式でsympyが8時間停止 |

## 7. 主要な結論

1. **ND²は公式資産から再現可能であり、10 synthetic systems 中2系で真の数式を厳密に回復する。** NDformer誘導は unguided MCTS に対し明確に優位（平均R² 0.860 対 0.576）で、探索量ではなく方向づけによって効いている。

2. **回復失敗の原因は一様ではない。** 予算6倍の対照実験により、探索律速（HCR）・未収束（MP）・頭打ち（CR）を分離した。無ノイズデータで誤式がR²≈1に達する系（FHN/WC/GR）は識別可能性の問題であり、計算時間では解決しない。

3. **NDformerの数式生成能力はdecoder最終ブロックに集中する。** 1層のみのfine-tuning（23.7%のパラメータ）が全層FTの89%の改善をhold-out testで達成し、同一ステップ予算では3層に分散させるより優れる。

4. **数式構造はencoderの2ブロック間で形成される。** 貪欲rolloutのTEDが 31.1 → 8.9 へ急落する。

5. **probeが示す「読み出せる層」と、activation interventionが示す「因果的に効く層」は逆順である**（Spearman −1.0）。単一の指標で層の重要性を語ることはできない。

## 8. 今後の課題

- **MPの予算をさらに延長**して収束の有無を確認する（CRは無意味、FHN/WC/GRは識別可能性の問題なので効果は見込めない）
- **識別可能性への対処**: 初期条件の多様化・軌道長の増加によりデータの励起を高め、誤式がR²≈1に到達できないようにする
- **RQ7の決着**: Phase 7/8のMCTS評価問題数を増やし、policyレベルの改善が formula-level へ波及するかを検定する
- **Pareto選択の検証**: 真式が候補集合に存在しながら複雑度ペナルティで選外になっていないか、`candidate_formulas` を精査する
- **層数の多いモデルでの追試**: k=3対照が成立する深さのSRモデルで層解析を再実行する

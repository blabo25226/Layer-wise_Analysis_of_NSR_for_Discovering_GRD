# Replication Gate

Replication is mandatory when a result is:
- surprisingly large
- novel
- contrary to prior results
- based on one seed/split
- a new layer mechanism
- a new GRN equation claim
- marked fragile by reviewer

Change at least one independent factor where feasible:
- seed
- split
- family
- noise
- initial condition
- clean rerun from a fresh process/artifact path

The confirmation result must be recorded separately.

Possible outcomes:
- replicated
- directionally replicated
- failed replication
- inconclusive

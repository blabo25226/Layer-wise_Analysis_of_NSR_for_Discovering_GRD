# Negative Result Recovery

Classify plausible bottlenecks:
- candidate generation
- candidate selection
- optimization
- evaluator/metric
- identifiability
- model architecture
- distribution shift
- data scarcity
- noise
- compute/search budget
- layer-ranking criterion
- implementation/reproducibility

For each plausible cause:
- evidence for
- evidence against
- experiment that distinguishes it

Prefer the cheapest experiment that separates multiple explanations.

Do not simply increase compute unless the evidence specifically points to budget limitation.

# Research Report

Required sections:
1. Executive summary
2. Hypothesis
3. Literature and novelty context
4. Preregistered design
5. Deviations
6. Methods actually run
7. Results
8. Statistical review
9. Independent review
10. Replication status
11. Interpretation
12. Limitations
13. Decision
14. Reproduction commands
15. Artifact manifest
16. Next hypotheses
17. human_review_priority

Allowed decisions:
- supported
- unsupported
- undecidable
- invalidated

Never invent missing numbers.
Trace numerical claims to stored artifacts.
Do not omit negative evidence.

# Literature Evidence

Search in this order:
1. primary paper
2. official code repository
3. official dataset/documentation
4. high-quality secondary source only for navigation

For every important source record:
- title
- authors
- year
- venue/status
- DOI/URL
- official implementation URL if any
- exact claim supported
- relevance to current hypothesis
- limitations
- relationship to root `source.md`

Novelty label:
- known
- adjacent
- plausibly_novel
- unverified

Never invent a citation.
Distinguish literature-derived fact from your inference.

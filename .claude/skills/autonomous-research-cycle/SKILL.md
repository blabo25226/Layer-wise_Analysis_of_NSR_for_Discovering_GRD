# Autonomous Research Cycle

1. Read `GPU_RUNclaude1/RESEARCH_LOOP.md`.
2. Reconstruct repository and research state.
3. Update the hypothesis tree.
4. Select one falsifiable high-information hypothesis.
5. Gather literature evidence.
6. Preregister before final-test access.
7. Implement.
8. Run reproducibility audit.
9. Smoke test.
10. Execute preregistered experiment.
11. Analyze raw outputs.
12. Perform independent adversarial review.
13. Pass replication gate when required.
14. Write the cycle report.
15. Create manifest/checksums.
16. Update persistent state and hypothesis tree.
17. Begin the next cycle unless a hard stop applies.

Never skip the report because the result was negative.
Never let the implementer be the only reviewer.

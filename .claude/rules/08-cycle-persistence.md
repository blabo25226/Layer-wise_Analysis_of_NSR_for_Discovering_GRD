# Cycle Persistence

Every cycle must leave:
- hypothesis
- literature note
- preregistration
- raw result references
- analysis
- statistical review
- independent review
- cycle report
- manifest
- checksums
- updated research state
- updated hypothesis tree

The cycle report is mandatory even for:
- negative
- null
- failed replication
- invalidated
- inconclusive

Every three cycles create a cumulative synthesis.
